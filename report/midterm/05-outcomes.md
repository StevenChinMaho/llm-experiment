# 三、預期完成之工作項目、成果及績效

## 1. 預期完成之工作項目

1. **完整的資源成本數據**：兩張顯示卡 × 5 種量化的生成與讀取速度、context 深度效應、部分卸載曲線、每 token 能耗（已完成）
2. **可預測的記憶體模型**：由啟動紀錄歸納的公式，能在實驗前以約 2% 的誤差預測最大 context（已完成並驗證）
3. **量化品質曲線**：5 種量化的 KL 散度與困惑度，並檢驗 KL 散度能否預測任務答對率的下降
4. **推測解碼的成本與效益**：MTP 在兩張顯示卡上的加速、VRAM 代價，以及最佳 n_max 與內容類型的關係
5. **「精度 × 思考」的權衡曲線**：3 種量化 × 3 種思考預算的答對率與等待時間，回答 RQ3
6. **計算工具的效果**：有、無工具時大數運算題的答對率，回答 RQ4
7. **部署建議**：依顯示卡（12GB／16GB）與用途（短問題深推理、長文件、日常問答）列出建議的量化等級、context 長度與 MTP 設定

## 2. 預期貢獻

**學術研究。** 本研究提供混合架構、思考型模型在消費級硬體上的系統化實測數據。初步結果已顯示兩個傳統架構沒有的現象：每 token 的 KV cache 只有傳統架構估算的約 13%，以及推測解碼會依草稿長度倍增遞迴狀態的記憶體。本研究也指出困惑度在 4 位元附近已無法分辨量化品質，KL 散度較適合作為評估指標。所有實驗腳本、原始紀錄與環境資訊都完整保存，可供重現與延伸。

**國家發展。** 在本地運行 LLM，資料不必離開使用者的電腦，有助於個人資料保護與資料主權，也降低對境外雲端服務的依賴。本研究以平價硬體證明可行性，並量化其代價，可作為學校、醫療院所與中小企業評估私有 AI 服務的參考。

**其他應用。** 本研究的記憶體模型與部署建議可直接供個人使用者、研究室與教學單位使用：只要知道顯示卡容量與預期用途，就能選出合適的設定，不必反覆嘗試。初步實驗中發現的作業系統超用記憶體、推測解碼的記憶體陷阱等問題，也能幫助使用者避免看似能執行、實則效能大幅下降的設定。
